## Capacités transversales (CT)

Transversales à toutes les disciplines, elles sont travaillées dans chaque objectif :
- **Collaboration** : prise en compte de l'autre, action dans le groupe
- **Communication** : codification du langage, circulation de l'information
- **Stratégies d'apprentissage** : acquisition de méthodes, gestion d'une tâche
- **Pensée créatrice** : développement de la pensée divergente, inventivité
- **Démarche réflexive** : élaboration d'une opinion, remise en question

## Lecture d'un objectif d'apprentissage PER

Chaque objectif a la structure :
```
CODE – Titre de l'objectif…
  1 …en [composante 1]
  2 …en [composante 2]
  3 …en [composante 3]
```

La **progression des apprentissages** est organisée en demi-cycles (colonnes du tableau).
Les **attentes fondamentales** décrivent ce que TOUS les élèves doivent maîtriser "au cours, mais au plus tard à la fin du cycle".
Les **indications pédagogiques** donnent des ressources, obstacles et notes pour l'enseignant.
